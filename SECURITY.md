# Security

md-tex opens documents from anywhere, so a Markdown file must not be able to run code, read other files, reach the network without your permission, or crash the app. If you find a way a document can do any of these, please report it privately.

Report it through GitHub's private vulnerability reporting: on the repository's **Security** tab, click **Report a vulnerability**. Please include the document (or a minimal one) that shows the problem, your operating system and the md-tex version (`md-tex --version`).

Security fixes go into the latest release only.
