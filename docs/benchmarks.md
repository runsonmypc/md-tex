# Benchmarks

Measured for 1.0 with `tools/bench.py`, which drives a release build of md-tex in real windows (see "Benchmarks" in [AGENTS.md](../AGENTS.md) to run it). Each budget is in `crates/mdt-bench/src/budget.rs`, and a run fails if any result is over it.

- **macOS:** MacBook Pro with an Apple M4, macOS 15.5, built-in display at 60 Hz.
- **Linux:** AMD Ryzen 7 7800X3D, NVIDIA GeForce RTX 4070 (driver 580), Pop!_OS 24.04, GNOME on Xorg, one 4K monitor at 60 Hz.

The documents are generated by `mdt-bench generate`: Markdown text of 100 KB, 1 MB and 10 MB, and a media document with about 500 equations, 50 diagrams and 200 photos of 12 megapixels.

## Notes on Linux

- **Launch.** About 200 ms of the launch is the NVIDIA driver creating the window's swapchain: during setup the main thread waits on X server requests that each return at the next 60 Hz refresh. On the same machine, the CPU's integrated graphics (Mesa) launches in about 220 ms, but every frame is then copied to the NVIDIA card at 4K, which costs missed frames while scrolling. md-tex's own work before the first frame is about 50 ms (about 20 ms on the M4).
- **Memory.** Linux counts shared library pages that macOS leaves out. Of the 211 MB, about 155 MB is library code: the NVIDIA driver (about 55 MB), `libLLVM` (about 45 MB, loaded because the Vulkan loader opens every installed driver) and md-tex's own code. The memory md-tex writes to is about 60 MB.
- **Idle CPU.** An empty window of GPUI, the UI framework, uses 0.20% of a core at idle on this machine; md-tex adds the rest.
